# 鲸鱼娘文档基线

- 版本：v0.2
- 日期：2026-10-25
- 状态：M5A 已实现；M5B～M5D 仍为规划
- 适用仓库：`Whale-girl`

## 1. 文档地图

| 文档 | 内容 | 维护时机 |
|---|---|---|
| `docs/ARCHITECTURE.md` | 系统上下文、分层、模块边界、数据所有权、扩展方式 | 架构或模块边界变化 |
| `docs/INTERFACES.md` | 接口清单、稳定性、输入输出、错误、幂等和测试 | 任何跨边界接口变化 |
| `docs/DATA_MODEL.md` | SQLite 表、字段、索引、迁移和保留策略 | 任何表结构变化 |
| `docs/CONFIGURATION.md` | 环境变量、默认值、校验、人设格式 | 任何配置变化 |
| `docs/ERROR_CODES.md` | 错误分类、重试策略、用户可见行为 | 任何错误语义变化 |
| `docs/adr/` | 架构决策记录 | 难以回滚或影响多个模块的决策 |

## 2. 当前状态与规划

当前已实现并验收：

- M2：QQ 私聊、群聊观察、@、唤醒词、断线重连。
- M2.5：DeepSeek 私聊 AI、唯一人设、短期上下文、回退和限流。
- M3：SQLite 消息持久化、去重和查询。
- M4：群聊 AI、群级上下文、群级限流和沉默策略。
- M5A：SQLite v2、出站消息持久化、turn、会话和跨重启上下文。
- 当前 74 项自动化测试通过。

当前尚未实现：

- 压缩摘要、长期记忆和会话状态卡。
- 调用审计表。
- token 预算和中转站。
- `/healthz`、`/status`。
- 管理后台、工具和 Skill 注册。

这些能力在文档中标记为 `draft` 或“规划”，不能当作已实现接口使用。

## 3. 阅读约定

- **当前实现**：仓库中已有代码和测试。
- **规划**：已确定方向，尚未编码。
- **草案**：用于讨论，可能变化。
- `stable`：稳定契约，破坏性变更需要升版本。
- `internal`：内部端口，允许调整但必须同步所有实现。
- `draft`：不能作为稳定代码依赖。
- `deprecated`：计划移除。

## 4. 单一事实来源

- 内部类型以 `src/whale_girl/ports/` 和 `src/whale_girl/domain/` 为准。
- 数据库结构以 `infrastructure/persistence/sqlite.py` 中的迁移为准。
- 环境变量以 `bootstrap/config.py` 和 `.env.example` 为准。
- 错误语义以 `ports/llm.py`、`application/ai_guard.py` 和 `docs/ERROR_CODES.md` 为准。
- 文档负责索引、语义和约束，不复制完整实现。

## 5. 更新规则

任何功能完成时至少检查：

1. 是否新增或修改了跨边界接口？更新 `INTERFACES.md`。
2. 是否修改了表或字段？更新 `DATA_MODEL.md` 和迁移测试。
3. 是否新增了环境变量？更新 `CONFIGURATION.md` 和 `.env.example`。
4. 是否新增了错误码或改变失败行为？更新 `ERROR_CODES.md`。
5. 是否做了难以回滚的架构选择？新增 ADR。
6. 是否泄露了 Key、Token、Cookie 或聊天正文？如有，禁止提交并立即轮换。
