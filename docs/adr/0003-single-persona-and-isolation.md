# ADR-0003 单一人设、单平台单账户与会话隔离

- 状态：Accepted
- 日期：2026-10-24
- 决策者：项目维护者
- 关联接口：`IF-PER-001`、`IF-CTX-001`、`IF-POL-001`

## 背景

鲸鱼娘是陪伴型 Agent，需要保持稳定人格。每个社交平台只使用一个账户，但未来可能接入多个平台。

如果不同账户有不同人设，或不同平台自动共享私聊记忆，会造成身份混乱和隐私泄露。

## 决策

- 所有平台共享同一个 Agent 身份和唯一人设。
- 每个社交平台只允许一个账户；当前 QQ 小号是唯一账户。
- 上下文和未来记忆按 `(platform, account_id, conversation_type, conversation_id)` 隔离。
- 不自动把私聊记忆带到群聊。
- 不自动把平台 A 的记忆带到平台 B。
- 跨平台身份绑定必须显式配置、可审计、可撤销。
- 全局记忆只保存非隐私的 Agent 自我设定和长期目标。

## 后果

正面：

- 人格稳定。
- 默认隐私边界清晰。
- 不同会话不会串线。

负面：

- 跨会话连续性需要显式设计。
- 同一用户在不同平台不会被自动识别。
- 需要额外的状态卡和记忆作用域。

## 替代方案

- 每个平台独立人设：破坏“同一个人”的产品目标。
- 自动按昵称/QQ 跨平台合并：误合并和隐私风险高。

## 迁移与验收

- 当前 `ConversationKey` 已按平台和会话隔离。
- M5 新增 `agent_sessions` 和 `memory_items` 时必须保留作用域字段。
- 增加群聊/私聊记忆隔离测试。
- 跨平台绑定在 M6 以后单独设计。
